## Running Locally

Clone the repository:

```bash
git clone https://github.com/collcame/portfolio.git
```

Navigate to the project directory:

```bash
cd portfolio
```

Open `index.html` in a web browser.

On Windows PowerShell:

```powershell
Start-Process .\index.html
```

No additional dependencies, frameworks, or build tools are required.

## Deployment

The website is deployed using GitHub Pages.

Deployment configuration:

- Source: Deploy from a branch
- Branch: `main`
- Directory: `/ (root)`

Changes pushed to the main branch trigger a GitHub Pages deployment.
